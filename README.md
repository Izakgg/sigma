# 🤖 Site Interativo de Conceitos de IA - Drag & Drop

Um website interativo e responsivo para aprender sobre Inteligência Artificial arrastrando caixas de conceitos!

## ✨ Características

- **Drag & Drop Funcional**: Arraste os conceitos de IA da sidebar para o canvas
- **Touch Support**: Funciona perfeitamente em dispositivos móveis e tablets
- **Design Moderno**: Interface visual atrativa com gradientes e animações suaves
- **Responsivo**: Adapta-se a qualquer tamanho de tela
- **14 Conceitos de IA**: Machine Learning, Deep Learning, Neural Networks e mais
- **Remover Elementos**: Duplo clique para remover um conceito do canvas
- **Resetar Layout**: Botão para limpar todos os conceitos do canvas

## 🚀 Como Usar

1. Abra `index.html` no seu navegador
2. Veja a lista de conceitos de IA na sidebar esquerda
3. **Arraste qualquer conceito** para a área branca no centro
4. **Organize livremente** os conceitos na ordem desejada
5. **Duplo clique** em um conceito para remover do canvas
6. Use **🔄 Resetar** para limpar tudo

## 🛠️ Arquivos

- **index.html** - Estrutura HTML
- **styles.css** - Estilos e layout responsivo
